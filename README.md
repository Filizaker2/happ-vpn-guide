## Где скачать Happ

Скачивайте только из официальных источников. Под видом «Happ на ПК» и «Happ Plus» распространяют сборки с вирусами.

| Платформа | Где взять |
|---|---|
| Windows | официальный сайт **happ.su** или релизы на GitHub разработчика |
| macOS | App Store (Mac с M-чипом) или сайт happ.su |
| Android | Google Play («Happ — Proxy Utility»), APK с официального сайта |
| iPhone / iPad | App Store («Happ — Proxy Utility», есть версия **Happ Plus**) |
| Android TV | Google Play / APK |

> 💡 Ищете «happ github»? У Happ есть официальные релизы на GitHub. Проверяйте, что это репозиторий разработчика, а не форк с 3 звёздами, созданный вчера.

### Happ на GitHub: как скачать Happ на ПК с GitHub
1. Откройте официальный репозиторий разработчика (ссылка есть на happ.su).
2. Справа откройте **Releases** → последний релиз (метка *Latest*).
3. В **Assets** скачайте файл под свою систему: `…-x64-setup.exe` для Windows, `.dmg` для macOS, `.apk` для Android.
4. Не качайте Happ из «сборок» на файлообменниках и из репозиториев-клонов: подменённый VPN-клиент видит весь ваш трафик.

### Happ, Happ Plus и Happ Proxy Utility — в чём разница
| Название | Что это |
|---|---|
| **Happ — Proxy Utility** | основное приложение, его название в App Store и Google Play |
| **Happ Plus** | отдельное приложение того же разработчика с расширенными функциями |
| **Happ для ПК** | версия для Windows и macOS (с официального сайта или GitHub) |

Все три понимают одни и те же подписки и ключи.

## Happ на ПК (Windows и macOS)

1. Скачайте установщик с happ.su и установите.
2. Скопируйте ссылку подписки (`https://…`) или ключ (`vless://…`).
3. В Happ нажмите **«+»** → **«Вставить из буфера»**.
4. Выберите сервер и нажмите большую кнопку подключения.
5. Чтобы через VPN шли все программы (игры, Discord, Telegram Desktop), а не только браузер, включите в настройках **режим TUN**. Он требует запуска от администратора.

**Особенности Windows:** Happ на Windows не всегда применяет маршрутизацию и DNS из подписки. Если российские сайты (банки, Госуслуги) открываются медленно или не открываются, выключайте VPN на время работы с ними или используйте подписку с раздельной маршрутизацией (см. ниже).

## Happ на Android

1. Установите Happ из Google Play.
2. Скопируйте ссылку подписки → в Happ **«+» → «Вставить из буфера»**. Или отсканируйте QR-код.
3. При первом подключении разрешите приложению создать VPN.
4. Чтобы VPN не отваливался, отключите для Happ **оптимизацию батареи**: Настройки → Приложения → Happ → Батарея → «Без ограничений».

## Happ на iPhone

1. Установите **Happ — Proxy Utility** из App Store. Если в российском App Store приложения нет, его можно скачать с Apple ID другой страны.
2. Скопируйте ссылку подписки → откройте Happ → **«+» → «Вставить из буфера»**.
3. Разрешите добавить конфигурацию VPN (iOS спросит код-пароль или Face ID).
4. Включите подключение. Значок VPN появится в строке статуса.

> ⚠️ Apple по требованию РКН удаляет VPN-клиенты из российского App Store: в марте ограничили v2RayTun и Streisand, в июне ненадолго пропадал Happ, 27 октября удалили Incy. **Если Happ уже установлен, не удаляйте его**: обновления придут, а заново скачать может не получиться.

## Как добавить подписку или ключ

| Что у вас есть | Что делать |
|---|---|
| Ссылка `https://…/sub/…` | Это **подписка**. Добавьте один раз, серверы и обновления приходят сами |
| Ключ `vless://`, `hysteria2://`, `ss://` | Один сервер. «+» → «Вставить из буфера» |
| QR-код | «+» → «Сканировать QR» |
| Кнопка «Открыть в Happ» в боте или на сайте | Нажмите, подписка добавится автоматически |
| Ссылка `happ://crypt…` | Зашифрованная подписка. Вставляется так же, «+» → «Вставить из буфера» |

**Где взять ключи и серверы для Happ.** Сам Happ серверов не продаёт, кнопки «купить подписку Happ» в приложении нет. Ключ или подписку даёт VPN-сервис. Бесплатные ключи для Happ из каналов живут недолго, подробнее об этом — в статье [«Ключ для VPN»](https://github.com/Filizaker2/klyuch-dlya-vpn).

Подписка лучше одиночного ключа: если сервер заблокируют, сервис заменит его, а вам ничего не придётся вставлять заново.

## Happ не работает: что делать

**Пинг показывает n/a, но сайты открываются.** Это известный баг отображения пинга, а не поломка. Проверьте, открывается ли YouTube.

**Подключено, но ничего не грузится / Telegram висит на «Соединение…».** Скорее всего, ТСПУ провайдера пропускает только первые ~16 КБ на зарубежный IP и обрывает соединение. Переключитесь на сервер с **XHTTP** (мобильный интернет) или **Hysteria2** (Wi-Fi). Подробно — в статье [«Не работает YouTube / Telegram даже с VPN»](https://github.com/Filizaker2/ne-rabotaet-youtube-telegram).

**Ошибка подписки / пустой список серверов.** Нажмите «Обновить подписку». Если не помогло, проверьте, что подписка не истекла, и вставьте ссылку заново.

**Работало вчера, сегодня нет.** IP сервера могли заблокировать. Обновите подписку: сервис обычно меняет серверы за несколько часов. Если вы на одиночном ключе, нужен новый ключ.

**YouTube «сайт не найден».** Провайдер подменяет DNS. Включите в браузере «Безопасный DNS» (Chrome: Настройки → Конфиденциальность → Безопасность → Использовать безопасный DNS).

## FAQ

**Happ бесплатный?** Приложение бесплатное. Серверы — нет: бесплатные ключи из каналов и с GitHub живут от часа до пары дней и видят весь ваш трафик.

**Чем Happ отличается от Happ Plus?** Plus — отдельное приложение того же разработчика в App Store с дополнительными функциями. Для обычного подключения хватает обычного Happ.

**Как обновить Happ?** iPhone и Android — через стор. На ПК скачайте новый релиз с официального сайта или GitHub и установите поверх, подписка сохранится.

**Happ на телевизоре?** На Android TV — да, Happ есть в Google Play, подписку удобно добавить по QR-коду.

**Happ или v2RayTun / Hiddify?** Все читают одни и те же ключи. Happ проще и стабильнее обновляется. Сравнение — в [гайде по VLESS](https://github.com/Filizaker2/vless-reality-2026).
